3. BASE DE DONNÉES
================================================================================

SGBD : MySQL
- Version : Non spécifiée dans le code (supporte MySQL 8.4 selon commentaire)
- Fichiers : config/database.php, .env, database/schema.sql
- Rôle : Stockage des données

Moteur : InnoDB
- Fichiers : database/schema.sql (spécifié dans CREATE TABLE)
- Rôle : Moteur de stockage avec support des transactions et clés étrangères

Méthodes d'accès aux données : PDO (PHP Data Objects)
- Fichiers : config/database.php, app/Services/*.php, app/Controllers/*.php
- Rôle : Abstraction d'accès à la base de données
- Caractéristiques :
  - Prepared statements (PDO::ATTR_EMULATE_PREPARES = false)
  - Connexion persistante (PDO::ATTR_PERSISTENT = true)
  - Mode d'erreur exception (PDO::ATTR_ERRMODE = PDO::ERRMODE_EXCEPTION)
  - Fetch mode associatif (PDO::ATTR_DEFAULT_FETCH_MODE = PDO::FETCH_ASSOC)

Transactions : ACID
- Fichiers : app/Services/VenteService.php, app/Services/CaisseService.php, app/Services/ChargeCommandeService.php
- Rôle : Garantie de cohérence des données
- Méthodes : beginTransaction(), commit(), rollback()
- Utilisation : Ventes, caisse, commandes, stock

Contraintes et mécanismes importants :
- FOREIGN KEY : Clés étrangères pour l'intégrité référentielle
- UNIQUE : Contraintes d'unicité (username, email, code_cip, code_barre, etc.)
- CHECK : Contraintes de validation (prix_vente >= prix_achat, stock >= 0)
- INDEX : Index pour l'optimisation des requêtes
- AUTO_INCREMENT : Identifiants auto-incrémentés
- TIMESTAMP : Horodatage automatique (created_at, updated_at)
- DEFAULT : Valeurs par défaut
- NOT NULL : Champs obligatoires
- Soft delete : deleted_at (suppression logique)

Charset : utf8mb4
- Collation : utf8mb4_unicode_ci
- Fichiers : config/database.php
- Rôle : Support des caractères Unicode (emojis, caractères spéciaux)

Configuration :
- Host : localhost (configurable via .env)
- Port : 3306 (configurable via .env)
- Database : medecin (configurable via .env)
- Username : root (configurable via .env)
- Password : vide (configurable via .env)
