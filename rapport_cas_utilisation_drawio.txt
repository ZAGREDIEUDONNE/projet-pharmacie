1. ACTEURS (RÔLES UTILISATEURS)
================================================================================

Acteur 1 : ADMINISTRATEUR
- Code rôle : ADMIN / ADMINISTRATEUR
- ID rôle : 1
- Description : Administrateur système avec accès total
- Permissions : Toutes les permissions du système
- Accès : Dashboard admin, gestion utilisateurs, gestion rôles, audit, statistiques globales

Acteur 2 : ASSISTANT
- Code rôle : ASSISTANT
- ID rôle : 3
- Description : Assistant polyvalent avec accès à plusieurs modules
- Permissions : Ventes, caisse, stock, clients, commandes, inventaire
- Accès : Dashboard assistant, vente session, commandes, annulation, arrêt caisse, facturation

Acteur 3 : CHARGE DE COMMANDE
- Code rôle : CHARGE_COMMANDE / CHARGE_DE_COMMANDE
- ID rôle : 4
- Description : Responsable des commandes fournisseurs et stock
- Permissions : Stock, commandes fournisseurs, réception, fournisseurs
- Accès : Dashboard commande, saisie commande, réception, historique

Acteur 4 : VENDEUR
- Code rôle : VENDEUR
- ID rôle : 2
- Description : Vendeur au point de vente
- Permissions : Ventes, clients (lecture), stock (lecture)
- Accès : Module vente, création vente, impression ticket

Acteur 5 : COMPTABLE
- Code rôle : COMPTABLE
- ID rôle : 5
- Description : Comptable pour la gestion comptable
- Permissions : Comptabilité, plan comptable, journaux, états financiers
- Accès : Module comptabilité, plan comptable, journaux, balance, bilan
