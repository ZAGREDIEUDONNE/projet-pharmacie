================================================================================
FLUX ACTUEL (commandes)
================================================================================

commandes (ancien système)
    ↓
EcritureComptableService::genererEcrituresAchat()
    ↓
Écriture comptable générée avec:
    - reference_type = 'ACHAT'
    - reference_id = commandes.id
    - journal_code = 'AC' (Journal des achats)
    - compte débit: COMPTE_STOCK_MEDICAMENTS (montant HT)
    - compte débit: COMPTE_TVA_DEDUCTIBLE (si TVA > 0)
    - compte crédit: COMPTE_FOURNISSEURS ou COMPTE_BANQUE (montant TTC)
    - Mise à jour commandes.ecriture_id

   - Utilise le compte fournisseur 401

4. Intégrer dans ChargeCommandeService::receiveOrder()
   - Après la mise à jour du stock
   - Avant le commit de la transaction
   - Appeler genererEcrituresReception()
   - Gérer les erreurs et rollback

================================================================================
GESTION TVA
================================================================================

Le système actuel utilise:
- calculerHT(): montantTTC / (1 + tauxTVA)
- calculerTVA(): montantTTC - montantHT
- Taux TVA par défaut: 18%

Pour les réceptions:
- Utiliser supplier_order_items.tva (si présent)
- Sinon utiliser tva_globale de supplier_orders
- Sinon utiliser le taux par défaut (18%)

- reference_id: ID de l'opération

Pour les réceptions:
- reference_type = 'RECEPTION'
- reference_id = receptions.id
- Permet de retrouver l'écriture depuis la réception
- Permet de retrouver la réception depuis l'écriture

================================================================================
PRÉVENTION DES DOUBLONS
================================================================================

Méthode existante: ecrituresExistent()
- Vérifie si une écriture existe déjà pour reference_type/reference_id
- Utilisée dans genererEcrituresAchat()
- À utiliser dans genererEcrituresReception()

================================================================================
TRANSACTION
================================================================================

Flux transactionnel cible dans receiveOrder():
BEGIN TRANSACTION
    ↓
1. Créer reception
    ↓
2. Créer reception_items
    ↓
3. Mettre à jour supplier_order_items
    ↓
4. addStock() → stock_entries
    ↓
5. addStock() → mouvements_stock
    ↓
6. addStock() → stock
    ↓
7. genererEcrituresReception()
    ↓
8. Mettre à jour receptions.ecriture_id
    ↓
COMMIT

En cas d'erreur: ROLLBACK
