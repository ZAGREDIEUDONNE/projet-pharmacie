12. JAVASCRIPT
========================================

Variables globales:
- tables: {} (objet pour stocker les données des tableaux)
- nf: Intl.NumberFormat('fr-FR')
- moneyFormat: Intl.NumberFormat('fr-FR', { maximumFractionDigits: 0 })

Fonctions utilitaires:
- esc(value): échappement HTML
- money(value): formatage monétaire (FCFA)
- badge(value): génération de badges de statut

Fonctions de rendu:
- renderKpis(widgets, cash): rendu des 4 KPIs principaux
- renderDayStats(widgets): rendu des 4 indicateurs secondaires
- createTable(id, rows, columns, emptyText): création de table
- drawTable(id): rendu du tableau
- renderTables(data): rendu de tous les tableaux

Fonctions de tri:
- sortTable(id, key): tri du tableau
- toggleSort(id, key): basculement du tri

Fonction de recherche:
- filterTable(id): filtrage du tableau

Appel API:
- fetch('/assistant/api/dashboard', { headers: { 'X-Requested-With': 'XMLHttpRequest' } })
- Gestion des erreurs
- Affichage du loader
- Rendu du contenu
